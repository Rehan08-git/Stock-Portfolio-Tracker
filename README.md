# Stock Portfolio Tracker 📊
This is a simple Python program that calculates the total investment value of a user's stock portfolio.

## 📌 Description
In this project, the user can enter stock names and their quantities.
## 🚀 Features
- User input for stock names and quantity
- Predefined stock price dictionary
- Calculates total investment value
- Option to save results in a file (.txt)

## 🛠️ Technologies Used
- Python

## 📚 Concepts Used
- Dictionary
- Input/Output
- While loop
- If-else conditions
- Basic arithmetic
- File handling

## ▶️ How to Run
1. Open the file in Python IDLE or any IDE  
2. Run the program  
3. Enter stock name and quantity  
4. View total investment value  

## 📷 Output
Displays total investment value in the console and optionally saves it to a file.
